# 南法 + 巴黎随身行程地图

单文件 HTML 行程地图，基于用户提供的 2026 年 6 月法国南法与巴黎旅行计划制作。

## 功能

- Leaflet 地图路线与每日点位。
- 输入目的地后定位到地图上的对应地点。
- 时间轴卡片按天筛选，包含天气敏感点和主动删减建议。
- 每个地点带 Google Maps 导航、小红书检索入口。
- 餐厅卡片带大众点评、小红书入口、支付方式标签。

## 使用

直接打开 `index.html`，或部署到 Vercel / GitHub Pages。页面不需要地图 API key，但需要联网加载 Leaflet CDN 和 OpenStreetMap 瓦片。
